One kind, funny fortune for the houseplant on the windowsill — "A sunbeam is coming to your windowsill tomorrow — lean in, little one, and drink it like the best gossip of the season." — entered in make.fun's Fortune in a Pot bounty.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints it.
